# vrx identity (generated)

Generated by vrx's `scripts/brand-sync.sh` from vrx d0ef3c3. **Do not edit
anything here.** The identity has one source, the identity package: the vrx
repo's `brand/` (brand.toml, IDENTITY.md, logo/, fonts/). Change it there,
then run the script.

| File | What |
|---|---|
| `IDENTITY.md` | the identity: the mark, construction, palette, type, rules |
| `DESIGN_SYSTEM.md` | how the design system works here: where the look comes from, running the pipeline (full or incremental), the type band, the usability floors, and fixing a UI flaw in the system with a promoted-or-local trailer on every UI commit (G086) |
| `design.toml` | the package's design overrides over the UI standard (absent when the identity sets none); `design_build.py` resolves it |
| `brand.toml` | the names, identifiers (USB, Matter, hostname), palette and font roles every surface reads |
| `palette.json` | the palette, for code that draws in it |
| `logo/<shape>-<ground>.svg` | the logos: mark and wordmark, on dark, on light, one colour |
| `png/<shape>-<ground>.png` | renders, 256 px tall, each on its ground |
| `fonts/` | the faces and their licences, the exact files the image ships |
| `design/` | the design system as a static site: open `design/index.html`. Foundations (colour, type, spacing, radius, elevation, gradient, motion), every component's variants, sizes and states in each display tier, and the usability floors, all drawn from the resolved standard. Its faces and logos sit beside it |
| `ui-standard.toml` | the UI standard from evrx-rt a764accc: type sizes by role (points), spacing and radii (millimetres), the colour slots and schemes, motion. Units are normative: lengths in mm, type in pt, pixels derived from the panel's density |

The rules that matter most when you are in this repo: the name is **vrx**,
written exactly so; a surface a person sees never spells the name, a colour,
a face or the logo by hand, it reads them from the package; the product
always carries "powered by vrx" on its About screen.
