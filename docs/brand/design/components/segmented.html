Lengths are millimetres and type sizes are points in the standard. This page draws them at 160 ppi: 1 mm = 160 / 25.4 = 6.2992 px and 1 pt = 160 / 72 = 2.2222 px. Border widths are device pixels and stay pixels.

Resolved rules

The layers, base first; each later layer wins
basecontainer: radius = radius_mm.sm, border = border_px.hairline, border_colour = colour.outline, hit = control_mm.sm, height = control_mm.sm, motion = micro.select; segment: min_width = size_mm.touch_along, pad_x = spacing_mm.md, border = border_px.hairline, border_colour = colour.outline; label: type = type.label, colour = colour.text
variant plainno change
size mdno change
state restno change
state hoversegment: layer = colour.primary, layer_opacity = opacity_permille.hover
state pressedsegment: layer = colour.primary, layer_opacity = class.pressed_layer_permille
state selectedsegment: fill = colour.primary; label: colour = colour.on_primary, ground = colour.primary
state focusfocus_ring: colour = colour.focus, stroke = border_px.regular, inset = border_px.hairline
state disabledcontainer: opacity = opacity_permille.disabled
