Text Field

Parts: container, input, label, helper, focus_ring. Interactive: a focus ring and a disabled state are required. 2 variants, 2 sizes, 5 states.

Lengths are millimetres and type sizes are points in the standard. This page draws them at 160 ppi: 1 mm = 160 / 25.4 = 6.2992 px and 1 pt = 160 / 72 = 2.2222 px. Border widths are device pixels and stay pixels.

The layers, base first; each later layer wins
basecontainer: radius = radius_mm.sm, border = border_px.hairline, border_colour = colour.outline, pad_x = spacing_mm.md, hit = control_mm.md, height = control_mm.md, motion = micro.focus; input: type = type.body, colour = colour.text; label: type = type.label, colour = colour.text_secondary; helper: type = type.caption, colour = colour.text_secondary, ground = colour.page
variant outlinedno change
variant filledcontainer: fill = colour.surface_high, border_colour = colour.surface_high; label: colour = colour.text
size mdno change
size compactcontainer: pad_x = spacing_mm.xs, height = control_mm.sm, hit = control_mm.sm
state restno change
state hovercontainer: border_colour = colour.text_secondary
state focuscontainer: border = border_px.regular, border_colour = colour.focus; focus_ring: colour = colour.focus, stroke = border_px.regular, inset = border_px.hairline
state errorcontainer: border = border_px.regular, border_colour = colour.error; helper: colour = colour.error
state disabledcontainer: opacity = opacity_permille.disabled
