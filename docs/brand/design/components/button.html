Button

Parts: container, label, icon, focus_ring. Interactive: a focus ring and a disabled state are required. 4 variants, 3 sizes, 5 states.

Lengths are millimetres and type sizes are points in the standard. This page draws them at 160 ppi: 1 mm = 160 / 25.4 = 6.2992 px and 1 pt = 160 / 72 = 2.2222 px. Border widths are device pixels and stay pixels.

Resolved rules

The layers, base first; each later layer wins
basecontainer: radius = radius_mm.sm, border = border_px.hairline, pad_x = spacing_mm.lg, gap = spacing_mm.sm, hit = control_mm.sm, elevation = elevation.0, motion = micro.press; label: type = type.label_lg; icon: size = icon_mm.sm
variant filledcontainer: fill = colour.primary, border_colour = colour.primary; label: colour = colour.on_primary; icon: colour = colour.on_primary
variant tonalcontainer: fill = colour.primary_container, border_colour = colour.primary_container; label: colour = colour.on_primary_container; icon: colour = colour.on_primary_container
variant outlinedcontainer: border_colour = colour.outline; label: colour = colour.text; icon: colour = colour.text
variant textcontainer: pad_x = spacing_mm.sm; label: colour = colour.primary; icon: colour = colour.primary
size smcontainer: height = control_mm.sm, pad_x = spacing_mm.md; label: type = type.label
size mdcontainer: height = control_mm.md
size lgcontainer: height = control_mm.lg, pad_x = spacing_mm.xl; icon: size = icon_mm.md
state restno change
state hovercontainer: layer = colour.primary, layer_opacity = opacity_permille.hover
state pressedcontainer: layer = colour.primary, layer_opacity = class.pressed_layer_permille
state focusfocus_ring: colour = colour.focus, stroke = border_px.regular, offset = spacing_mm.xs
state disabledcontainer: fill = colour.page, border = border_px.none; label: colour = colour.text_secondary; icon: colour = colour.text_secondary
