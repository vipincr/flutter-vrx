Resolved rules

The layers, base first; each later layer wins
basering: size = icon_mm.sm, radius = radius_mm.pill, border = border_px.regular, border_colour = colour.outline, hit = control_mm.sm, motion = micro.select; dot: size = spacing_mm.sm, radius = radius_mm.pill; label: type = type.body, colour = colour.text, ground = colour.page
variant plainno change
size mdno change
state restno change
state hoverring: layer = colour.primary, layer_opacity = opacity_permille.hover
state pressedring: layer = colour.primary, layer_opacity = class.pressed_layer_permille
state selectedring: border_colour = colour.primary; dot: fill = colour.primary
state focusfocus_ring: colour = colour.focus, stroke = border_px.regular, inset = border_px.hairline
state disabledring: opacity = opacity_permille.disabled; label: opacity = opacity_permille.disabled
